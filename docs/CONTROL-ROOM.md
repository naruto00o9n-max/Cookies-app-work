# دليل لوحة الإشراف والتسجيل

افتح **مساحتي → لوحة الإشراف الكاملة** أو زر لوحة الإشراف في الرئيسية. يظهر للمشرفين حسب صلاحيات ديسكورد، ولا يحتاج العضو إلى معرفة أسماء الأوامر.

## الأقسام

| القسم | ما يمكنك فعله |
| --- | --- |
| الأعضاء | البحث، مشاهدة صافي الشهر، فتح الملف والأعمال والفصول، المسجلون الجدد، تغيير اللقب، إيقاف الدخول أو استرجاعه |
| الأعمال | البحث، إضافة عمل، الاسم وأول فصل مدفوع، إتاحة/إيقاف التسجيل، العزل، أسعار خاصة وربط أزورا |
| سجلات الفصول | البحث في رقم الفصل والعضو والعمل والتخصص، اختيار الشهر، تحرير سجل محدد أو حذفه |
| المالية | تقرير المستحقات، إضافة مكافأة أو خصم باختيار العضو، تصدير تقرير الدفع |
| التخصصات والأسعار | الأسعار العامة والخاصة، التعطيل، إعادة حساب السجلات بالسعر المختار |
| الشهور والأرشيف | إنشاء شهر وتفعيله، عرض السجلات القديمة وتنظيم الأرشيف |
| ربط الفريق | مزامنة أسماء وصور ديسكورد، مركز أزورا وحالة الأجهزة المرتبطة بالإشعارات |
| البيانات والحماية | تصدير واستعادة النسخ، سجل العمليات، أدوات التنظيف بتأكيد واضح |
| إعدادات المساحة | العملة ويوم وساعة الدفع وحد التذكير وفحص الاتصال |

إيقاف عضو يمنع وصوله الجديد إلى بيانات الفريق، ولا يحذف سجلاته. إذا كان جهازه غير متصل بالإنترنت فقد يحتفظ بنسخة البيانات التي رآها سابقًا؛ عند الاتصال تُرفض الجلسة وتُمسح النسخة المحلية. لا يستطيع المشرف إيقاف حسابه نفسه. الألقاب لا تغيّر اسم العضو الحقيقي أو صلاحياته في ديسكورد.

## رؤية فصول العضو بالتحديد

الأعضاء → اختر العضو → **أعماله** → اختر عملًا. ستجد أرقام الفصول، والتخصص الذي أداه، والشهر والتاريخ والمبلغ والملاحظات لكل سجل. استخدم البحث أو فلاتر الشهر والتخصص. المكافآت والخصومات تظهر منفصلة.

الأعمال → اختر العمل → **الفريق**. كل عضو يظهر مع عدد الفصول المختلفة والمهام. اضغط عليه لرؤية فصوله وتخصصاته في هذا العمل وحده؛ ويمكن فتح ملفه الكامل.

الصافي الحالي يستثني الأعمال المعزولة مثل تقرير الدفع. أرقام الأرشيف مميزة ولا تُضاف تلقائيًا إلى دفع الشهر الحالي.

## تسجيل فصل أو فصول كثيرة

افتح **تسجيل فصول**. اختر العمل بالبحث أو من آخر الأعمال التي استخدمتها. يُحفظ آخر اختيار لكل حساب على الجهاز، مع التخصصات المفضلة لكل عمل.

يمكن اختيار فصل واحد، أو نطاق «من / إلى»، أو فصول متفرقة. إذا كان التخصص واحدًا، طبّقه على الجميع. إذا اختلف، فعّل التخصيص لكل فصل واختر تخصصًا من قائمة واضحة أمام رقم الفصل. لا تحتاج كتابة قائمة تخصصات مفصولة بفواصل.

التقدير يميز الفصول المجانية والمكررة. التحقق النهائي على الخدمة؛ في الأعمال المرتبطة بأزورا يُتحقق من النشر ومن عدم تسجيل نفس الفصل والتخصص لعضو آخر في الشهر نفسه. تعديل الملاحظات فقط لا يغيّر السعر القديم المتفق عليه للسجل.

## ساحة الأبطال والمستويات

الترتيب يعرض الفصول المختلفة أو الخبرة أو الأعمال أو المستحقات للفترة المختارة، مع منصّة للمراكز الأولى وبطاقة تقدم لكل عضو. تنفيذ تخصصين للفصل نفسه يُعد مهمتين وفصلًا واحدًا.

الخبرة = 10 نقاط لكل مساهمة مختلفة في عمل/فصل/تخصص. تكرار نفس المساهمة في شهر آخر لا يمنح خبرة إضافية، والمكافآت والخصومات لا تشتري مستويات. المستويات والأوسمة مشتقة من السجلات المحفوظة، وتتحدث عند تصحيحها أو حذفها. لا يختلق التطبيق نتائج أو أعضاء أو أوسمة مكتسبة.

## تحديث أسماء وصور الجميع من ديسكورد

1. في Discord Developer Portal افتح تطبيق البوت ثم **Bot**، وفعّل **Server Members Intent**.
2. ضع **توكن البوت** في Vercel → المشروع → Settings → Environment Variables، باسم `DISCORD_BOT_TOKEN` مع Production. احتفظ به في Vercel فقط.
3. أعد النشر، ثم افتح لوحة الإشراف → ربط الفريق → **تحديث أعضاء ديسكورد**.

المزامنة تستخدم نك نيم السيرفر، ثم الاسم المعروض، ثم اسم المستخدم، وتستخدم صورة السيرفر إن وجدت. تجلب الجميع بصفحات، بما فيهم من لم يدخلوا التطبيق. لا يحتاج ذلك تشغيل البوت على Railway. يُحدّث الدليل في الخلفية بعد فتح التطبيق، مرة كل ست ساعات، دون تأخير ظهور السجلات. ويُحدّث أيضًا عبر المهام الدورية عند إعدادها.

المسجلون الجدد في لوحة الإشراف هم من أكملوا دخول التطبيق فعليًا؛ وجود شخص في ديسكورد وحده لا يُحسب تسجيلًا في التطبيق. التواريخ تُحفظ من تسجيلات الدخول القادمة، ولا تُختلق للبيانات القديمة.

## إعداد Expo والإشعارات

اتبع [إعداد Expo](EXPO-SETUP.md). لا تشارك كلمة مرورك؛ ضع رمز الوصول في GitHub ثم شغّل الإجراء المخصص. يحتفظ المستودع بمعرّف المشروع العام فقط. إذا كنت تستخدم ESign، يجب أن يدعم ملف توقيعك Push Notifications لنفس Bundle ID وأن تتوفر اعتمادات APNs لنفس فريق Apple؛ وجود شهادة توقيع وحده لا يثبت ذلك.
