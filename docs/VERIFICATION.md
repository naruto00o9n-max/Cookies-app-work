# التحقق

نجحت الاختبارات المحلية التالية قبل الرفع:

- TypeScript للتطبيق ولـ API، وتجميع Next.js للإنتاج.
- 12 اختبارًا لمنطق الفصول والمستحقات: أرقام عربية ونطاقات، مجاني ومكرر، أسعار خاصة دقيقة، مكافآت/خصومات، صلاحيات العضو، عزل وأرشيف، إعادة تسمية، استيراد بيانات البوت وCSV.
- تكامل API محلي على **بيانات تجريبية فقط**: جلسة موقعة، رفض الطلب غير المصادق، منع كتابة العضو باسم آخر وإدارة الأسعار، تسجيل وحفظ ورفض تكرار، استعادة نسخة، حماية المهام المجدولة وتصدير XLSX.
- معاينة Chromium بمقاس 390×844: دخول تجريبي، اختيار عمل وتخصص، تسجيل ثلاثة فصول، عودة للشاشة الرئيسية مع الصافي والفصول المحدثة؛ دون أخطاء JavaScript.
- تجميع Expo لحزم Android وiOS والويب، وتوليد مشروعي Android وiOS الأصليين. هذه الحزم ليست APK/IPA ولا تثبت التشغيل على جهاز.

اجتاز ملفا GitHub Actions فحص actionlint.

لم تتوفر أسرار MongoDB/Discord أو حسابات توقيع. لم تُختبر قاعدة الفريق، OAuth الحقيقي، إرسال push، API أزورا الحية، ولا أجهزة فعلية. تطبيق المعاينة يعمل ببيانات مستقلة. نجاح بناء الملفات الأصلية يُحدد من GitHub Actions بعد إتاحة المستودع وتشغيله، وليس من هذا التقرير.

بناءً على طلب المستخدم أُزيلت بيانات المعاينة والدخول التجريبي من النسخة النهائية. بيانات الاختبار معزولة في tests فقط. حُفظ اتصال MongoDB محليًا في ملف مستثنى من Git؛ فحص SRV أعاد ENOTFOUND، ولم تُقرأ أو تُعدّل سجلات الفريق. لم يُنشر أي سرّ في المستودع.

نجح تشغيل GitHub Actions رقم 38328866052: فحص الكود والاختبارات وAPK وIPA. فُحص APK بأداة Android apksig الرسمية: توقيع v2 صحيح؛ يدعم arm64-v8a وarmeabi-v7a. فُحص IPA: منصة iPhoneOS، آيفون وآيباد، دون LC_CODE_SIGNATURE غير فارغ ودون مجلدات _CodeSignature. هذه ليست تجربة على أجهزة فعلية. الملفات الأولى بُنيت قبل ربط عنوان الخدمة؛ تُعاد بناؤها بعد ضبط العنوان.

تحديث 1.1: نجح بناء Next production وفحص TypeScript للهاتف و15 اختبارًا، بما فيها كشف الفصول الجديدة والفصول العشرية وتحديد المستلمين، وتصدير واجهة الهاتف للويب. الإشعارات الفعلية على iPad تحتاج Project ID واعتماد APNs وتوقيعًا يدعمه؛ لم يُثبت وصول تنبيه إلى جهاز حقيقي بعد.
