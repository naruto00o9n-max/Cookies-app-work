# Cookies للويب · 1.4.1

الموقع يستخدم واجهات التطبيق نفسها عبر Expo / React Native Web. يبني Vercel الواجهة من mobile إلى dashboard/public/app أثناء البناء؛ الملفات الناتجة لا تدخل Git. الرابط الرئيسي يفتح /app/ وتبقى API في أصل الموقع نفسه.

## الدخول والتثبيت

دخول الويب يستخدم جلسة Discord الموقعة في HttpOnly cookie؛ لا يُنسخ توكن OAuth إلى المتصفح. التطبيق الأصلي يحتفظ بتدفق PKCE وتخزينه الآمن. كلاهما يستخدم حسابات الفريق وMongoDB نفسها. العمليات المعتمدة على cookie ترفض Origin خارجيًا. API الخاصة لا تُخزن في Service Worker.

في Android والكمبيوتر، استخدم زر إضافة إلى الشاشة الرئيسية أو قائمة التثبيت في المتصفح. في Safari على iPhone/iPad، استخدم مشاركة ثم إضافة إلى الشاشة الرئيسية، وافتح الأيقونة. على iOS 16.4 أو أحدث تتاح Web Push للتطبيق المضاف للشاشة الرئيسية، ولا تحتاج إعداد مفتاح APNs الخاص بتطبيق iOS الأصلي.

## الإشعارات

WEB_PUSH_PUBLIC_KEY وWEB_PUSH_PRIVATE_KEY وWEB_PUSH_SUBJECT مضبوطة في Vercel Production؛ المفتاح الخاص للخادم فقط. /api/mobile/web-devices يتحقق من العضوية ويحفظ اشتراك الجهاز باسم العضو في web_devices. تُقبل فقط عناوين HTTPS المعروفة لخدمات الإرسال، وتُحذف الاشتراكات المنتهية عند 404/410. إشعارات الفريق نفسها تُرسل إلى أجهزة التطبيق والويب؛ فشل قناة لا يمنع محاولة القناة الأخرى. لا ترسل إشعارات تجريبية لأعضاء الفريق أثناء الاختبارات.

الموافقة على الإذن وحدها ليست نجاح الربط. يحفظ التطبيق الاشتراك في API قبل عرض التفعيل. تسجيل الخروج يفصل هذا الجهاز عن المستخدم. iOS الأصلي ما زال يحتاج APNs وملف provisioning مطابقًا؛ Web Push لا يصلح توقيع IPA.

## القراءة دون اتصال

الـ Service Worker يحفظ هيكل التطبيق والخطوط والأصول الثابتة فقط. لا يحفظ /api أو OAuth أو ردود حسابات الفريق. يمكن للمستخدم الذي سبق له الدخول عرض آخر snapshot محلي وفق سلوك التطبيق؛ الكتابة تحتاج الإنترنت. يتغير رقم cache مع bundle الجديدة. أسرار MongoDB وديسكورد وVAPID لا تُمرر إلى عملية تصدير Expo.

## المالية والتعليم

الحركات المالية في شاشة مستقلة عن فصول الأعمال. اختيار النوع صريح، العضو قابل للبحث بالصورة والاسم، والمبلغ موجب حتى ثلاث منازل عشرية. المراجعة توضح الصافي قبل وبعد والعضو والسبب والشهر النشط. الأسماء المالية القديمة في سجلات البوت لا تظهر كروايات؛ يُحفظ تاريخ السجلات ومبالغها دون ترحيل أو حذف في MongoDB.

التوب يستخدم قوائم الفترة وطريقة الترتيب والتخصص؛ الافتراضي الشهر الحالي والفصول وكل التخصصات. حُذفت بطاقات التعليم القديمة ومحتوى الدليل الموسّع ومساره من التطبيق. الجولة المختصرة خطوط وعبارات داخل الواجهة تشير إلى الأزرار الفعلية لتسجيل أول فصل، ثم الملف الشخصي والتوب فقط. تتقدم بالإجراءات الفعلية، ولا تعتبر التسجيل ناجحًا قبل نجاح الحفظ. تُحفظ مرحلتها لكل عضو؛ يمكن تخطيها دون تعطيل بقية التطبيق، وتنتهي بعبارة «استكشف التطبيق بنفسك». لا تستخدم طبقة حوار.

- COOKIES_WEB_SKIP_INSTALL=1 npm --prefix dashboard run build
- PORT=3000 HOSTNAME=127.0.0.1 node dashboard/.next/standalone/dashboard/server.js
- BASE_URL=http://localhost:3000/app/ node mobile/tests/features-ui.mjs
- BASE_URL=http://localhost:3000/app/ node mobile/tests/walkthrough-ui.mjs
- BASE_URL=http://localhost:3000/app/ node mobile/tests/pwa-ui.mjs

اختبارات الواجهات تستخدم ردود API محلية معزولة فقط؛ لا تتضمن بيانات نموذجية أو دخولًا تجريبيًا في المنتج المنشور. اختبار Service Worker منفصل لأن اعتراض API في Playwright لا يعمل بشكل موثوق عندما يعترض Service Worker الطلبات.
