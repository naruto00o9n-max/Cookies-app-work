# Cookies API ولوحة الفريق

Next.js API عند الطلب، يستخدم MongoDB الحالية. جميع العمليات تتطلب جلسة حقيقية بحساب Discord، وتُنفذ صلاحيات الإدارة على الخادم. لا يوجد دخول تجريبي أو سجلات وهمية.

```bash
npm ci
npm run dev
```

اضبط متغيرات `.env.example` في بيئة الخدمة. لا ترفع `.env.local` ولا أسرار القاعدة وديسكورد. API لا تحتاج تشغيل بوت Discord. راجع [دليل الانتقال](../docs/MOBILE-MIGRATION.md).
